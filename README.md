### 🚀 Featured Projects

#### 🛡️ [NetShield AI — Intelligent Network Intrusion Detection](https://github.com/tanishv1018-hub/NetShield-AI)

An AI-powered cybersecurity application designed to detect suspicious network activity and make model predictions interpretable.

- Developed an interactive **React dashboard** for monitoring security alerts and network activity.
- Integrated **SHAP explainability** to visualize how individual features influence machine learning predictions.
- Worked with **FastAPI and MySQL** for alert management and backend integration.
- Implemented an AI-assisted explanation interface to help users understand security alerts.

**Tech:** Python · React · FastAPI · MySQL · PyTorch · SHAP

#### 📚 [AI Lesson Creator — LLM-Powered Educational Content Generation](https://github.com/tanishv1018-hub/AI-Lesson-Creator)

An AI-powered application that automates educational lesson creation using external research and structured quality evaluation.

- Built a lesson-generation pipeline using **Google Gemini APIs**.
- Integrated research from **books, websites, and YouTube** to support educational content generation.
- Designed **two independent quality-control layers** for factual accuracy and instructional quality.
- Used **Pydantic schemas** for structured LLM outputs and a **Streamlit interface** for lesson review and editing.

**Tech:** Python · Gemini API · Streamlit · Pydantic · REST APIs

#### 🎵 [SongSense — Multi-Label Music Genre Classification](https://github.com/tanishv1018-hub/Songsense)

A deep learning-based audio classification system designed to identify multiple musical genres from audio signals.

- Processed audio using **Librosa**, Mel spectrograms, and audio feature extraction.
- Implemented a **Parallel CNN architecture** for multi-label genre prediction.
- Experimented with audio embeddings and classification techniques.
- Evaluated performance using **Micro F1, Jaccard Score, and Top-3 Accuracy**.

**Tech:** Python · PyTorch · TensorFlow · Librosa · Deep Learning

#### ⚽ [Footy GOAT — Interactive Football Draft Game](https://github.com/tanishv1018-hub/Footy-GOAT)

A football-themed web application that combines player knowledge, strategy, and interactive gameplay.

- Built an interactive football player drafting experience using **React and Vite**.
- Designed a player pool featuring footballers with individual attributes including **Pace, Shooting, Passing, Dribbling, Defending, Physical, and IQ**.
- Developed a player selection system that allows users to build their own football lineup.
- Focused on responsive UI design, reusable React components, and interactive game mechanics.

**Tech:** React · Vite · JavaScript/TypeScript · CSS
